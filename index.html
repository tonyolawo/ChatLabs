Skills for the harnesses your team already uses

Beyond chat channels, we build skills and tools that plug directly into frontier AI harnesses, so your docs, systems, and workflows become callable actions inside the assistants you already run.

  • Drop-in integration OpenAI, Anthropic, Copilot, opencode. Same skill, every harness.
  • Clean tool schemas Well-typed tool definitions the models actually call without fiddling.
  • Harness-agnostic design Write once, run in any agent. No rewrites when you switch providers.
  • Ships with docs Examples and guides so your team is productive in days, not quarters.
chatlabs / skills.ts 
import { skill } from "@chatlabs/sdk";

export const orderStatus = skill({
  name: "check-order-status",
  tools: [orders.lookup, shipping.track],
  run: async ({ orderId }) => {
    const order  = await orders.lookup(orderId);
    const status = await shipping.track(orderId);
    return summarize(order, status);
  },
});

// Runs in OpenAI, Anthropic, Copilot & opencode.
export default orderStatus;
